## ▶️ How to Run the Programs

1. Install a compatible Java Development Kit (JDK).
2. Clone this repository:

   ```bash
   git clone REPOSITORY_URL
   ```

3. Open the project folder in your IDE.
4. Navigate to the required `.java` file.
5. Compile and run a program from the terminal:

   ```bash
   javac HelloWorld.java
   java HelloWorld
   ```

   Replace `HelloWorld` with the name of the class containing your `main()` method. Run these commands from the directory containing the source file.
